HOST MESSAGES
=============

Put your recorded host messages in this folder. The Host Messages page
(http://localhost:3000/host.html) plays them in order of the number at the
start of each file name:

  01 welcome.mp3
  02 phones out.wav
  03 how to join.m4a
  ...

- Number every file. Files without a number at the start are played last.
- Use 01, 02, ... (or 1, 2, ... 10): numbers are compared as numbers, so 10 comes after 9.
- Supported formats: .mp3, .wav, .m4a, .ogg, .webm, .mp4, .aac, .flac
- After adding, removing or renaming files, press Stop and then Start on the
  Host Messages page to reload them.
